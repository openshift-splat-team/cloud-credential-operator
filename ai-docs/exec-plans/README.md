# Exec-Plans

Active feature implementation plans for the Cloud Credential Operator.

## Active Plans

Place feature execution plans in `active/` as you implement new capabilities.

**Guidance and templates live in Tier 1**:
- Templates: [Tier 1 Exec-Plans Guide](https://github.com/openshift/enhancements/tree/master/ai-docs/workflows/exec-plans)
- Template file: `ai-docs/workflows/exec-plans/template.md`
- Usage instructions: `ai-docs/workflows/exec-plans/README.md`

## Workflow

1. Create `active/<feature-name>.md` using the Tier 1 template
2. Reference the relevant enhancement PR
3. Delete the plan after all knowledge is extracted to domain/ or architecture/ docs
